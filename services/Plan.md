LLM-сервис

Calendar-сервис
JSON → Яндекс Календарь

Сервис/модуль контекста сообщений
Объединение нескольких сообщений, определение продолжения, временное хранение.

Desktop-клиент на Go
микрофон → STT → LLM → Calendar

Telegram-бот
текст/ГС → STT → LLM → Calendar

Интеграция и автоматизация
.env, запуск всех сервисов, установка зависимостей, .bat, развёртывание из Git.
